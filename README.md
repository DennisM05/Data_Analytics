# Data Analytics

In diesem Projekt erfasse und analysiere ich täglich Kennzahlen aus vier Bereichen:

- **Körper:** Ich erfasse meine Schritte pro Tag, um meine Bewegung im Alltag zu untersuchen.
- **Herz:** Ich erfasse die Zeit mit Freunden und Familie, um zu sehen, wie viel Zeit ich für soziale Kontakte aufbringe.
- **Mind / Lernen:** Ich erfasse die Anzahl neuer japanischer Wörter pro Tag, um meine Lernaktivität zu untersuchen.
- **Geist:** Das Thema und die passende Kennzahl werden noch festgelegt.
